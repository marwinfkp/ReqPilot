# E1 evidence: run `111b163e` on E1-SYNTHETIC-v1

This directory holds the evidence for the P3 E1 measurement. The benchmark itself is frozen in
`data/gold/e1_synthetic_v1/`. It is a **synthetic reference benchmark**, generated by an AI assistant and reviewed by
the sole project author. It is **not** an independently annotated gold standard (see its `BENCHMARK.md`).

| File | What it is | Written by |
|---|---|---|
| `run.json` | Run id, benchmark manifest hash, provider/model, prompt name/version/sha256, configuration, counts, tokens | `scripts/run_e1.py extract` |
| `predictions.jsonl` | The 60 accepted requirements, as the E1 harness sees them (reference id, statement, spans) | same |
| `pairs.jsonl` | The 58 candidate pairs the harness proposed for adjudication | same (`propose_pairs`, unchanged) |
| `ADJUDICATION_SHEET.md` | The pairs side by side, with the AI assistant's *suggested* verdicts and the unpaired items | the AI assistant |
| `adjudications.suggested.jsonl` | Those suggestions, before confirmation. Not verdicts | the AI assistant |
| `adjudications.jsonl` | The verdicts E1 was computed from, confirmed by the project author on 2026-09-22 | the project author |
| `e1_report.md` | The E1 report | `scripts/evaluate_extraction.py`, unchanged |
| `diagnostics.json` | Supplementary descriptive figures. **Not E1**, no targets | `scripts/run_e1.py diagnostics` |

## Reproduce

These commands need a migrated database (`DATABASE_URL`). They were run against PostgreSQL 16.2 + pgvector 0.6.2.
They also need `LLM_PROVIDER=openai`, `LLM_MODEL_DEFAULT` and `LLM_API_KEY` in `.env`. The first command is
**billable**: in this run, 63 provider calls.

```bash
alembic upgrade head
```

```bash
LLM_FIXTURE_MODE=live LLM_TIMEOUT_SECONDS=180 python scripts/run_e1.py extract --benchmark data/gold/e1_synthetic_v1 --out docs/evaluation/e1-synthetic-v1
```

```bash
python scripts/evaluate_extraction.py --gold data/gold/e1_synthetic_v1 --run <run id> --actor <analyst id> --adjudications docs/evaluation/e1-synthetic-v1/adjudications.jsonl --report docs/evaluation/e1-synthetic-v1/e1_report.md
```

```bash
python scripts/run_e1.py diagnostics --benchmark data/gold/e1_synthetic_v1 --run <run id> --adjudications docs/evaluation/e1-synthetic-v1/adjudications.jsonl --out docs/evaluation/e1-synthetic-v1
```

Model output varies between live runs. No sampling seed is set: the model rejects `temperature`, and the API offers
no seed that ReqPilot uses. A rerun therefore produces a new run, whose predictions must be adjudicated again. The
figures here belong to run `111b163e` alone.
