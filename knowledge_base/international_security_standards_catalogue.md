# International Application Security Standards Catalogue

> REFERENCE CATALOGUE. Each entry is a document-level pointer to a real, publicly available security standard, with a short scope description written in ReqPilot's own words. Entries contain no text from the standards and no requirement numbers. Always obtain the current version from the publisher before relying on it.

## SEC-REF-01 OWASP Application Security Verification Standard (ASVS)
Topics: authentication, access_control, encryption, audit_logging, secure_development, third_party_api_security
Official title: OWASP Application Security Verification Standard
Issuing body: OWASP Foundation (open community standard)
Date: Version 4.0.3 published 2021; a version 5 has been released since - verify the current version with the publisher
Obtain from: https://owasp.org/www-project-application-security-verification-standard/
Scope: A catalogue of security requirements for designing, building and testing web applications and services, organised by area such as authentication, session management, access control, input validation, cryptography, error handling and logging, data protection and API security, with verification levels for applications of increasing risk.
Reference entry only: this summary is not text of the standard. Obtain the official document from the publisher and upload it to the Knowledge Base for requirement-level evidence.

## SEC-REF-02 OWASP Top 10
Topics: secure_development, access_control, authentication
Official title: OWASP Top 10 - The Ten Most Critical Web Application Security Risks
Issuing body: OWASP Foundation (open community awareness document)
Date: 2021 edition; newer editions are published periodically - verify with the publisher
Obtain from: https://owasp.org/www-project-top-ten/
Scope: An awareness document describing the most common and critical categories of web application security risk, such as broken access control, cryptographic failures, injection and security misconfiguration, with guidance on prevention. It is commonly used as a minimum baseline for secure development training and security testing.
Reference entry only: this summary is not text of the document. Obtain the official document from the publisher for detailed guidance.

## SEC-REF-03 OWASP Mobile Application Security Verification Standard (MASVS)
Topics: authentication, encryption, secure_development
Official title: OWASP Mobile Application Security Verification Standard
Issuing body: OWASP Foundation (open community standard)
Date: Updated periodically - verify the current version with the publisher
Obtain from: https://mas.owasp.org/
Scope: Security requirements for mobile applications covering secure storage of data on the device, cryptography, authentication, network communication, platform interaction, code quality and resilience against tampering and reverse engineering. It is accompanied by a testing guide for verifying these requirements.
Reference entry only: this summary is not text of the standard. Obtain the official document from the publisher for requirement-level evidence.

## SEC-REF-04 OWASP API Security Top 10
Topics: third_party_api_security, access_control, authentication
Official title: OWASP API Security Top 10
Issuing body: OWASP Foundation (open community awareness document)
Date: 2023 edition - verify the current edition with the publisher
Obtain from: https://owasp.org/www-project-api-security/
Scope: An awareness document describing the most critical security risks of application programming interfaces, such as broken object-level and function-level authorisation, broken authentication, unrestricted resource consumption and unsafe consumption of third-party APIs.
Reference entry only: this summary is not text of the document. Obtain the official document from the publisher for detailed guidance.
